# TypeScript/JavaScript File Header (JSDoc)

Render this template only for a scope-matched file. Optional fields may be omitted when empty or redundant.

```ts
/**
 * [INPUT]
 * Types, modules, or contracts consumed by this file.
 *
 * [OUTPUT]
 * Public APIs, side effects, guarantees, or exposed behavior.
 *
 * [ROLE]
 * Architectural purpose within the system.
 *
 * [INVARIANTS]
 * Optional stable truths that should remain valid.
 *
 * [LOCAL_REVIEW_WHEN]
 * Optional file-specific triggers that invalidate this header.
 */
```
