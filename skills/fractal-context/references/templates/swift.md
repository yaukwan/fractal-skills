# Swift File Header (DocC)

Optional fields may be omitted when empty, redundant, or already covered by folder/root review triggers.

```swift
/// [INPUT]
/// Types, protocols, modules, or contracts consumed by this file.
///
/// [OUTPUT]
/// Public APIs, side effects, guarantees, or exposed behavior.
///
/// [ROLE]
/// Architectural purpose within the system.
///
/// [INVARIANTS]
/// Optional stable truths that should remain valid.
///
/// [LOCAL_REVIEW_WHEN]
/// Optional file-specific triggers that invalidate this header.
```
