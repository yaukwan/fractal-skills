# Level 1 Protocol

Level 1 is the root context layer. It exists to orient an agent quickly at repository entry.

## Required Sections

```md
## Project
- Phase:
- Last Reviewed:
- Primary Domains:

## Topology
- `path`: <what lives here>

## Local Maps
- `path/to/AGENTS.md`: <what this subtree owns>

## Global Constraints
- <rule>
```

## Optional Sections

```md
## Active Context
- `path`: <why it matters now>
```

## Hard Rules

- Keep root context short and navigational.
- Put global review logic in the fractal-context protocol instead of scattering local trigger sections.
- Do not turn the root file into an implementation dump.
